# TVFlow v2

Dépôt canonique de TVFlow.

Ce dépôt remplace progressivement `bobcatfr63/TVFlow`, l'ancien `bobcatfr63/iptv` et le dépôt de distribution `bobcatfr63/IPTV-Releases`.

La migration conserve le code Android, les scripts DevServer/ADB, les configurations de build et les archives utiles. Les APK sont distribués via les Releases de ce dépôt, pas comme blobs Git ordinaires.
